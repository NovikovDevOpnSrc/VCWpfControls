# План: библиотека «Vibe Coded WPF Controls» (этап 1 — GridControl)

## Контекст

Создаётся новая библиотека WPF-контролов **VCWpfControls** (заголовок «Vibe Coded WPF Controls») с нуля в пустом каталоге `Z:\Work\VibeCoding\VCWpfControls`. Цель этапа 1 — **GridControl** с функционалом не хуже бесплатных аналогов (DataGrid из WPF Toolkit, Extended WPF Toolkit Community). Требования: пермиссивная лицензия с отказом от ответственности (→ MIT), документация и примеры на русском, английском и китайском, тестирование при разработке.

**Решения пользователя:** платформы `.NET 6 + .NET 8` (net6.0-windows + net8.0-windows); тесты — unit + UI-автоматизация + бенчмарки; документация — DocFX-сайт + XML-комментарии; этап 1 разбивается на под-этапы 1.1/1.2/1.3 с работающим контролем после каждого.

## Архитектура GridControl

Ключевой принцип — **отделение движка данных от UI** (движок не использует Dispatcher/WPF-типы → тестируется без STA):

- **Движок данных** `Grid/Data/`: `GridDataManager` (обёртка над ItemsSource), сортировка (цепочка multi-key компараторов), фильтрация (композиция предикатов), группировка (дерево групп), агрегаты. Чистые классы, полный unit-покрытие.
- **Колонки**: абстрактный `GridColumnBase` (Header, Binding, Width/Min/Max, Visible, ReadOnly, Frozen, CellTemplate/CellEditingTemplate) + TextColumn, CheckBoxColumn, ComboBoxColumn, DateColumn, NumericColumn, TemplateColumn; `ColumnAutoGenerator` через рефлексию.
- **Рендеринг**: `GridControl : ItemsControl` с кастомным шаблоном; строки — панель на базе VirtualizingStackPanel с рециклингом контейнеров; синхронный скролл заголовков и строк; star-sizing (`Width="*"`) и auto-width.
- **MVVM**: DependencyProperties, routed commands (Delete/BeginEdit/Export), отменяемые события (Validating, Filtering и т.п.).

## Функционал по под-этапам

**1.1 Ядро** — привязка (IEnumerable/ObservableCollection/ICollectionView, авто-колонки), типы колонок, resize/reorder/hide/freeze, UI-виртуализация (рециклинг, deferred scrolling), сортировка (мультиколоночная по Shift, индикаторы, кастомные компараторы), выделение (строка/ячейка, Single/Extended, Ctrl/Shift, чекбокс-колонка), редактирование (F2/Enter/Esc, read-only колонки, валидация IDataErrorInfo + INotifyDataErrorInfo), навигация с клавиатуры, копирование в буфер, добавление/удаление строк.

**1.2 Аналитика** — фильтрация (filter row + меню фильтра колонки: текст/список значений/диапазоны чисел и дат), группировка (drag-to-group, панель групп, expand/collapse), итоги (футер + групповые: Sum/Min/Max/Avg/Count), асинхронные сортировка/фильтрация (background task).

**1.3 Завершение паритета** — экспорт CSV / Excel (ClosedXML, MIT) / HTML, буфер обмена HTML, темы Light/Dark + акценты, High-DPI, локализация встроенных строк (RU/EN/ZH), доступность (AutomationPeers: IGrid/ITable/ISelection, полная клавиатурная навигация), row details, контекстные меню.

## Тестирование

- **Core.Tests** — движок данных: компараторы, фильтры, группы, агрегаты, авто-генерация колонок (без STA).
- **Control.Tests** — контрол в STA-потоке: применение шаблона, привязки, DP-колбэки, команды, валидация.
- **UiTests (FlaUI)** — запуск демо-приложения: клик по заголовку → сортировка, редактирование ячейки, фильтрация, выделение, смена темы/языка.
- **Benchmarks** — 10k/100k/1M строк: скролл, сортировка, фильтрация, память; отчёт в CI.
- Покрытие coverlet; тесты запускаются в CI на windows-latest.

## Документация и демо (RU/EN/ZH)

- DocFX-сайт: разделы en/, ru/, zh/ (getting started, установка, функции, cookbook) + автогенерируемый API-reference; переключатель языков; публикация на GitHub Pages.
- **Демо-приложение** — страница-пример на каждую функцию (привязка, сортировка, фильтры, группировка, редактирование, экспорт, темы, 1M строк) с переключателем языка RU/EN/ZH; служит и живой документацией, и целью для UI-тестов.

## Рекомендуемые дополнения к вашим 4 пунктам (включены в план)

1. **CI/CD (GitHub Actions)**: сборка + все тесты + docfx build на каждый push; матрица Debug/Release.
2. **NuGet-пакет**: SourceLink, deterministic build, снимволы (snupkg); публикация по тегу.
3. **Версионирование и релизы**: SemVer, CHANGELOG (Keep a Changelog), автоматический release-flow.
4. **Бенчмарки производительности** с отчётом в CI (контроль регрессий виртуализации).

6. **Локализация самого контрола** (строки фильтров, групп, агрегатов) из коробки в 3 языках.
7. **Темы Light/Dark + High-DPI** (PerMonitorV2).
8. **Демо-приложение** как галерея примеров и стенд для UI-тестов.
9. **Качество кода**: nullable enable, Roslyn-анализаторы, .editorconfig, порог покрытия, C# 10-совместимый синтаксис (ограничение net6.0).
10. **ROADMAP.md** на будущие контролы (TreeListView, PropertyGrid, …) — чтобы архитектура сразу предусматривала расширение.
11. **CONTRIBUTING.md, SECURITY.md, шаблоны issues** — если проект будет открытым.

## Верификация

1. `dotnet build -c Release` — оба TFM без предупреждений.
2. `dotnet test` — все 3 тестовых проекта зелёные.
3. `dotnet run --project src/VCWpfControls.Demo` — ручной чек-лист: сортировка кликом, редактирование (Enter/Esc, валидация), фильтр, группировка, итоги, экспорт CSV/XLSX, смена темы и языка, плавный скролл 1M строк.
4. `dotnet run -c Release -p benchmarks/VCWpfControls.Benchmarks` — метрики производительности зафиксированы.
5. `docfx build docs` — сайт собирается, 3 языка доступны.
6. CI-пайплайн зелёный.
