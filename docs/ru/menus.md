# Меню

Библиотека темизирует стандартные WPF-типы меню — `Menu`, `MenuItem` и `ContextMenu` —
через неявные стили, мержимые ThemeManager'ом на всё приложение (тот же механизм, что у
тематических Button/ComboBox/TextBox). Новых типов учить не нужно: пишите обычные WPF-меню
— и они следуют Light/Dark/HighContrast.

```xml
<Menu>
    <MenuItem Header="_Файл">
        <MenuItem Header="_Открыть…" InputGestureText="Ctrl+O" Click="Open" />
        <Separator />
        <MenuItem Header="_Выход" InputGestureText="Alt+F4" Click="Exit" />
    </MenuItem>
    <MenuItem Header="_Правка">
        <MenuItem Header="Автосохранение" IsCheckable="True" IsChecked="True" />
    </MenuItem>
</Menu>
```

- **Метрики** (по гайдлайнам): пункты от 32px, карточки-поверхности со скруглением 8px и
  внутренним отступом 4px, hover через `HoverBackgroundKey`, неактивные — 45% opacity.
- **Роли**: один шаблон обслуживает верхний уровень (заголовки/пункты) и вложенные
  пункты/заголовки — у верхнего уровня коллапсируют колонки чека/хоткея/стрелки; открытый
  верхний пункт подчёркивается акцентом (Win11). Вложенные пункты показывают галочку (при
  `IsCheckable`), `InputGestureText` (приглушённо, справа) и стрелку подменю.
- **Разделители** темизируются через `MenuItem.SeparatorStyleKey` (`<Separator/>` внутри
  меню подхватывает автоматически) — линия 1px `SeparatorLineKey`.
- **Клавиатура**: стандартное поведение WPF — access-ключи через `_` в заголовках
  (Alt+Ф открывает «Файл»), навигация стрелками, прыжки по первой букве; фокус — общий
  фокус-ринг.
- **Высокая контрастность**: все кисти идут через токены палитры, алиасящие живые
  системные цвета — меню следуют контрастной схеме пользователя.
- **Контекстное меню заголовков грида** (правый клик по заголовку колонки) следует теме
  автоматически — оно строится из обычных `ContextMenu`/`MenuItem`.

На странице Menus демо — панель меню (access-ключи, хоткеи, чекбокс-пункт,
неактивный пункт, разделители) и область с контекстным меню.
