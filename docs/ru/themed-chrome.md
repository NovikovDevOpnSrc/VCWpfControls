# Тематический хром

Помимо контролов, определяемых библиотекой, каждая ходовая стоковая поверхность WPF
следует Light/Dark/HighContrast через неявные стили, мержимые ThemeManager'ом:
`Button`, `TextBox`, `ComboBox`/`ComboBoxItem`, `CheckBox`, `RadioButton`, `Hyperlink`,
`ToggleButton`, `Menu`/`MenuItem`/`ContextMenu`, `StatusBar`/`StatusBarItem` — и набор
«завершения хрома»:

- **TabControl / TabItem** — прозрачная полоса с линией 1px, привязывающей её к
  странице; выбранная вкладка несёт акцентное подчёркивание (как открытое меню);
  пункты 32px с клавиатурными фокус-визуалами;
- **Expander** — тоггл-заголовок с вращающейся стрелкой; контент ниже (Space
  переключает — канал стоковый);
- **GroupBox** — рамка 1px со скруглением, заголовок выбивает верхнюю границу;
- **Slider** — дорожка на `BarFillKey`, акцентный круглый тамб с обводкой поверхности
  (обязательный `PART_Track` сохраняет нативные стрелки/клавиатуру);
- **ProgressBar** — дорожка `BarFill` + акцентный индикатор (`PART_Track`/
  `PART_Indicator`; размер индикатора управляет сам контрол);
- **ListBox / ListBoxItem** и **TreeView / TreeViewItem** — поверхность + граница,
  пункты 32px, hover и пара SelectionBackground/SelectionText (паттерн строк грида);
  пункты дерева с отступом 16px на уровень и тематическим экспандером;
- **ToolTip** — карточка-поверхность (радиус 4, текст caption-размера).

Регрессия паритета палитр охраняет всё семейство: набор неявных стилей обязан быть
идентичен в Light/Dark/HighContrast. Высокая контрастность едет на алиасах токенов —
поверхности следуют контрастной схеме пользователя.

Страница **Chrome** в демо показывает весь набор вживую.
