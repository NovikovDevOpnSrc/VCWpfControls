# Редакторы

Пространство имён `VCWpfControls.Editors` — автономные редакторы значений, использующие общую
тему библиотеки (`GridResources.*`) и принцип «движок без UI».

## MaskedTextBox

```xml
<editors:MaskedTextBox Mask="+7 (000) 000-00-00" />
```

Язык маски: `0` цифра, `9` необязательная цифра, `#` цифра или знак, `L`/`?` обязательная /
необязательная буква, `A`/`a` буква или цифра, `C`/`c` любой символ, `\` экранирует следующий
символ в литерал. Остальные символы — литералы.

- Литералы отображаются автоматически и пропускаются при вводе; `PromptChar` (по умолчанию `_`)
  помечает пустые позиции.
- `Value` содержит введённые символы; `IncludeLiterals="True"` добавляет литералы.
- `IsMaskComplete` — заполнены ли все обязательные позиции.
- Backspace очищает предыдущую позицию, Delete — текущую, вставка проверяется по маске.
- Наследуется от `TextBox`: выделение, буфер обмена и стили работают как обычно.

## NumericUpDown

```xml
<editors:NumericUpDown MinValue="0" MaxValue="10" Increment="0.25" FormatString="C2" Value="2.5" />
```

- `Value` (decimal, двусторонняя привязка) всегда приводится к `MinValue`/`MaxValue`.
- Шаг применяется кнопками автоповтора, стрелками, PageUp/PageDown (10 шагов) и колесом мыши;
  введённый текст разбирается с текущей культурой (некорректный ввод откатывается).
- Отображение: `DecimalPlaces` (по умолчанию — по масштабу шага) или `FormatString`;
  `IsReadOnly` запрещает правку; событие `ValueChanged` уведомляет об изменениях.


## AutoComplete

Поле ввода с выпадающими подсказками (`Editors.AutoComplete`), также доступно как колонка
грида (`GridAutoCompleteColumn`):

- `ItemsSource` — любой IEnumerable; строки сравниваются напрямую, объекты — по `ItemTextPath`;
- сопоставление по умолчанию — культуранезависимое вхождение без учёта регистра;
  заменяется через `ItemFilter`;
- `MinimumPrefixLength` (по умолчанию 1) и `MaxSuggestions` (по умолчанию 8) управляют
  появлением списка;
- **стрелки вверх/вниз** перемещают выбор, **Enter/Tab** принимают, **Esc** закрывает,
  клик принимает; после принятия срабатывает `SuggestionAccepted`; `Text` поддерживает
  двустороннюю привязку, `SelectedItem` несёт принятый элемент.

```xml
<editors:AutoComplete Text="{Binding City}" ItemsSource="{Binding Cities}" />
<columns:GridAutoCompleteColumn FieldName="Name" ItemsSource="{Binding Names}" Width="190" />
```
