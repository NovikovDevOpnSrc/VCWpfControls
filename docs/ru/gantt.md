# Диаграмма Ганта

Форумное исследование назвало Gantt крупнейшим open-source пробелом WPF; VCWpfControls закрывает его в три слоя.

## Контрол

```xml
<gantt:GanttView Tasks="{Binding Tasks}"
                 Dependencies="{Binding Links}"
                 AutoSchedule="True"
                 ShowCriticalPath="True"
                 TimescaleUnit="Week" />
```

- **Слева**: иерархия задач в TreeListView (Name/Start/Finish/%; иерархия через
  `GanttTask.ParentId`); сплиттер регулирует ширину.
- **Справа**: таймлайн — бары с заполнением по %, ромбы-milestone, стрелки зависимостей
  FS/SS/FF/SF, пунктирная линия «сегодня», зум день/неделя/месяц (`TimescaleUnit`).
- `TaskRowHeight` держит обе половины в lock-step; таймлайн скроллится горизонтально и
  зеркалит вертикальный скролл дерева.
- `AutoSchedule` запускает движок при загрузке/изменении (нарушающие последователи
  сдвигаются); `ShowCriticalPath` обводит критические бары/связи акцентом. Двойной клик
  по бару → `BarDoubleClicked` (на `GanttTimelinePanel`).

## Соответствие гайдлайнам (Oracle FusionFX / SAP Fiori / Smartsheet)

Диаграмма следует гайдлайнам большой тройки:

- **Двухуровневая ось времени** — верхний ряд (месяцы, на зуме Month — годы) над рядом
  юнита зума (требование Oracle и Fiori).
- **Сводные бары** — родительские задачи рисуются как Oracle summary-бары (тонкая
  полоса с эндкэпами) с взвешенной по длительности готовностью всех потомков
  (`GanttEngine.SummaryCompletion`), а не собственным числом.
- **Легенда** — полоса, закреплённая внизу таймлайна (`ShowLegend`), со всеми фигурами
  на экране: задача, сводная, веха, критический путь, базовый план, нерабочие дни
  (локализовано ×3).
- **Метки баров** — `ShowBarLabels` (по умолчанию выключено, как советует Oracle)
  рисует имя задачи после бара с обрезкой по ширине чарта.
- **Дискретный wheel-зум** — колесо мыши шагает Day ↔ Week ↔ Month через
  `TimescaleUnit` представления (привязки и тулбары остаются в синхронизации).
- **Пан перетаскиванием** — драг пустого места чарта скроллит таймлайн (курсор-рука).
- **Курсоры** — `SizeWE` над краями баров (ресайз), `SizeAll` над телом (перенос).
- **Цвет задачи** — `GanttTask.BarBrush` (null = тема): паттерн Fiori для
  категорий/статусов.

## Базовые планы и инлайн-правка

- **Baseline** — задайте `BaselineStart`/`BaselineFinish` у задач: под фактической
  полосой рисуется тонкая серая полоса базового плана (переключается `ShowBaseline`);
  tooltip полосы показывает диапазон базового плана и отклонение старта в днях.
- **Инлайн-правка** — колонки дерева (Name/Start/Finish/%) редактируют задачу напрямую
  (write-through): коммит даты перезапускает автопланирование и критический путь и
  поднимает `TaskEdited` — ровно как драг полосы.

## Нерабочие дни

`Calendar` (класс `GanttCalendar`: выходные дни недели + явные даты праздников) переводит
диаграмму на рабочее время:

- Таймлайн подкрашивает выходные и праздники под сеткой.
- С `AutoSchedule` длительности и лаги считаются в **рабочих** днях, и сдвинутая задача
  никогда не начинается в нерабочий день («Пт + 1» = понедельник, а не суббота).
  Удовлетворяющие связям ручные даты не трогаются.
- `CriticalPath` остаётся на календарных днях (относительные резервы).
- `null` (по умолчанию) — прежняя календарная арифметика, поведение существующих
  диаграмм не меняется.

```csharp
var calendar = new GanttCalendar();                 // Сб/Вс по умолчанию
calendar.Holidays.Add(new DateTime(2026, 11, 20));  // корпоративный выходной
view.Calendar = calendar;
```

## Drag-взаимодействия

Все правки выравниваются по дням и после попадания дат в задачу поднимают события:

- **Перенос** — тащите тело бара; Start и Finish сдвигаются вместе (milestone фиксированы).
- **Ресайз** — тащите левый/правый край бара; длительность меняется, минимум один день
  сохраняется.
- **Связь** — зажмите **Alt** и протяните от края бара к другому бару: за курсором идёт
  «резинка», отпускание создаёт зависимость `FinishToStart` (попадает в `Dependencies` и
  при включённом `AutoSchedule` сразу пересчитывает расписание).

```csharp
view.TaskEdited += (_, task) => Сохранить(task);                    // перенос/ресайз
view.LinkCreated += (_, dependency) => Сохранить(dependency);       // нарисованная связь
```

После правки обновляются обе половины: колонки дерева берут новые даты, движок перезапускает
`AutoSchedule`/`CriticalPath` — последователи сдвигаются, критическая цепь перестраивается живьём.

## Движок (без UI)

`GanttTask`/`GanttDependency` (FS/SS/FF/SF + лаги/опережения), `GanttEngine.AutoSchedule`
(только вперёд; `GanttCycleException` несёт путь цикла), `CriticalPath` (CPM-флоаты),
`BuildTimescale` (День/Неделя/Месяц, первый день недели по культуре). Unit-тесты без STA.
